**注**：hair / glass 指标的 dL NaN 是因合成数据中前景 / 背景掩码 < 50 px
（半透明/全前景），指标退化为 NaN 但 BNR 仍可比较。

### 消融结论

1. **去掉 shadow 后 BNR 上升**（10.566→12.781，6.063→6.834）：
   阴影的"明-暗渐变"让边缘带梯度更柔和。
2. **去掉 relight / harmonize 对 normal / complex_bg 几乎无影响**：
   印证 B6 的发现——当前 T04 / T06 实现相同，单独任一启用即可。
3. **全流程 D 的 dL 略劣于 no_shadow**（-15.52 vs -16.09）：
   阴影让"前景附近变暗"使 dL 绝对值略增，符合物理真实（接受此 trade-off）。

## 3. 主要失败归因（与 B6/B4 交叉印证）

1. **半透明 / 透明 / 薄纱**：单纯 RGB 输入下的 matting 任务固有困难，
   行业级方案（RobustMatting / MatteFormer）同样无法彻底解决。
2. **BiRefNet 在 veil 上将半透明区域识别为前景（alpha≈0.7）**：
   导致 veil SAD 在 refined 后仍达 20986（基线 24328，下降有限）。
   后续可考虑：**a)** 训练时增加半透明样本权重；**b)** Refiner 输出增加
   trimap 估计分支；**c)** 在 B 级合成数据上 fine-tune。
3. **Refiner 输入依赖粗 alpha 质量**：
   当粗 alpha 已经偏离 GT 时（如 transparent），refiner 的残差学习会"加速偏离"
   （残差 + scale）。可通过 residual_scale 衰减系数调小缓解。
