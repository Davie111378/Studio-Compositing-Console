> 用途：逐条验证演播室合成 Agent（Planner-DAG 八层架构版）的全部功能。

## 已知性能口径

- 冷启动（服务器重启后第一条）：BiRefNet 加载 ≈35s，之后单链 4–9s；
- 「标准/精修」含 Critic（VLM 评图 40–90s）；Web 端 Critic 限 1 轮；
- 前端 5 分钟超时保护，超时会明确报错建议改用「快速」。
