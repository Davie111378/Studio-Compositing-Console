# 实验报告 B4：抠图模型对比（BiRefNet baseline vs BiRefNet+AlphaRefiner 精修）

> 责任人：B 组
> 日期：2026-09-09
> 测试集：96 张合成 matting（8 类难例 × 12 张，物理隔离见 manifest.csv）

## 1. 核心结果（test 集 n=96）

| 指标 | BiRefNet@512（baseline） | BiRefNet@512 + AlphaRefiner（ours） | 相对下降 |
|---|---:|---:|---:|
| **SAD** ↓ | 12 999.31 | **5 615.47** | **−56.80 %** ✅ |
| **MSE** ↓ | 0.057314 | **0.023034** | **−59.81 %** |
| **Grad** ↓ | 5 860.86 | **2 765.58** | **−52.81 %** |
| **Conn** ↓ | 0.7899 | **0.3479** | **−55.95 %** |

> 验收门槛：SAD 相对下降 ≥ 10 %。**实际达成 −56.80 %，远超目标。**

## 3. 关键发现与归因

1. **hair / complex_bg / normal 几乎全胜（SAD ↓>80 %）**：
   Refiner 通过残差学习（`out = coarse + scale * (delta - 0.5)`）把 BiRefNet 在边界/纹理
   上的 1-2 像素抖动直接抹平。这正是 Refiner 设计目标。
2. **glass / transparent / semi 中等改善（-50% ~ -70%）**：
   这三类本质 alpha 歧义大，Refiner 难以完全消除"半透明是 0.5 还是 0.7"的人类标注噪声。
3. **veil 改善最小（-13.7%）**：
   薄纱区域 GT alpha 值本就在 0.1-0.6 之间且与原图亮度强耦合，Refiner 输出"接近 GT"的
   alpha 后，绝对差分仍较大（因为 GT 本身波动大）。属于 matting 任务的根本困难。

## 4. 模型结构

- **BiRefNet**：CVPR 2024 SOTA，220M 参数；本地权重 `ai-service/src/matting/birefnet_official/model.safetensors`。
- **AlphaRefiner**：轻量 UNet（base=32），3.35M 参数。4 通道输入（RGB + 粗 alpha）→ 1 通道输出。
  - 残差学习（粗 alpha 为起点，只学 delta），收敛快且不劣于 baseline。
  - Loss = `1.0·L1 + 1.0·一阶梯度 + 0.5·Laplacian`。

## 5. 训练配置

- 数据：合成 matting 数据集 train 768 / val 96 / test 96（按 manifest.csv 严格隔离）。
- 输入：384×384；batch 4；AdamW(lr=1e-3, wd=1e-4)；CosineAnnealing(T_max=80, eta_min=lr·0.05)。
- AMP fp16（CUDA）；80 epoch，~27 分钟；best epoch = 78，val = 0.0528。
- 显存占用 < 1.5 GB（BiRefNet 推理与 Refiner 训练共享 4 GB 卡）。
- 三件套：`config.json` / `train.log` / `metrics.csv` 全部落盘。

## 6. 复现命令

```bash
# 数据集与粗 alpha 准备
python training/scripts/train_refiner.py --prepare --infer_size 512
# 训练
python training/scripts/train_refiner.py --epochs 80 --bs 4 --lr 1e-3
# 推理（refined alpha）
python training/scripts/predict_alpha.py --model refined --split test \
  --out_dir experiments/fine_tuned/preds_refined --refine_size 384
# 评估
python training/scripts/evaluate_matting.py \
  --gts data/matting/test --preds experiments/fine_tuned/preds_refined \
  --gt_suffix _alpha --names_file data/matting/test_names.txt \
  --out experiments/fine_tuned/eval/eval_refined.csv --label Refined
# 视觉对比
python training/scripts/visualize_comparison.py \
  --inputs experiments/demo/inputs --gts data/matting/test \
  --baseline data/matting/coarse_cache/test \
  --ours experiments/fine_tuned/preds_refined \
  --out_dir experiments/fine_tuned/comparison --n 24
```

## 8. 局限与后续

- **未用真实人像数据**：GitHub 主站被墙，P3M-10k / AM-2k / Distinctions-646 暂无法下载。
  当前结果仅在**合成数据**上验证；真实数据微调列为下一阶段。
- **BiRefNet 推理尺寸 512 vs 1024**：512 比 1024 损失少量细节，但可让 baseline/refined
  在公平条件下对比；建议 1024 + Refiner 在真实数据上重新评估。
- **8 GB+ 显存机器上可改方案**：直接微调 BiRefNet 的 decoder（冻结 encoder），
  端到端训练，无须 Refiner 中间步骤 —— 预期可进一步提升 5–10 %。
