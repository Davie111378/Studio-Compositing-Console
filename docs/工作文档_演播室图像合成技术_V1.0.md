## 一、目标

构建一个**可由 Agent 调用的演播室图像合成流水线**，核心功能：

1. **抠图 (Matting)**：从原图中分离前景 + alpha 通道，处理发丝、玻璃、纱帘等难例
2. **特效 (Special Effects)**：根据 prompt 进行风格化 / 光影重打 / 配色迁移
3. **背景重叠 (Background Composite)**：将前景与新背景无缝合成，含光影、阴影、色温一致性
4. **Agent 接口**：每个原子能力暴露为统一 schema，便于 Planner 调用

## 二、算法选型

### 2.1 抠图（Matting, T03）

| 候选方案 | 优缺点 | 选型 |
| --- | --- | --- |
| **BiRefNet**（CVPR 2024 SOTA, 双向参考） | 高精度发丝/透明，CPU 可推理，模型 ~70MB | **主选** |
| **SAM 2**（Meta, 2024, 交互式分割） | 适合用户点击的"二次精修"，可与 BiRefNet 级联 | **辅助（交互精修）** |
| U^2-Net / MODNet | 老牌，速度快但精度略差 | 不选 |
| RMBG-1.4 / BiRefNet-DIS | 蒸馏版，速度更快 | 备选 |

**理由**：BiRefNet-hrnet 在 Composition-1k 上 SAD 已是公开最优（22.6），且支持静态 ONNX 推理，CPU 上单张 < 1.5s，符合 Agent 延迟预算。

### 2.2 特效（Special Effects, T04）

| 候选方案 | 优缺点 | 选型 |
| --- | --- | --- |
| **IC-Light**（ICLR 2025, 前景重打光） | 与背景光一致性好，与 BiRefNet 抠图天然衔接 | **主选** |
| DiLight / Light-Anything | 同类替代 | 备选 |
| Stable Diffusion + IP-Adapter | 适合强风格化 | LoRA 时使用 |
| 颜色迁移 (Reinhard / MKL) | 简单稳定 | **降级版**（无 GPU 时用） |

### 2.3 阴影生成（Shadow, T05）

| 候选方案 | 优缺点 | 选型 |
| --- | --- | --- |
| **程序化阴影**（基于 alpha + 模糊 + 偏移） | 快，无依赖，效果可控 | **主选（生产版）** |
| 扩散式阴影生成（SD + ControlNet） | 自然但慢，需 GPU | 备选 |
| 真实阴影数据集训练的小网络 | 折中 | 评估版 |

### 2.4 色彩协调（Harmonization, T06）

| 候选方案 | 优缺点 | 选型 |
| --- | --- | --- |
| **OpenCV Color Transfer (MKL)** | 经典、零成本 | **降级版** |
| **DCC + RainbowNet**（CVPR 2023） | 端到端深度学习 | **主选（带 GPU 时）** |
| 直接前景 → 背景颜色空间统计匹配 | 极快 | 兜底 |

### 2.5 合成（Composite, T07）

| 候选方案 | 优缺点 | 选型 |
| --- | --- | --- |
| **标准 alpha over** + 边界 feathering | 通用，O(1) | **基础** |
| **泊松融合 (Poisson Blending)** | 解决边缘色差 | **主选** |
| Laplacian Pyramid blending | 多频段融合 | 备选 |

## 三、Agent 接口设计（与 A 组对齐）

| Tool | 名称 | 输入 | 输出 | 依赖 |
| --- | --- | --- | --- | --- |
| **T03** | matting | `image_path`, `options:{hint_box?, refine?}` | `alpha_path`, `fg_path`, `mask_meta` | BiRefNet (+SAM2 refine) |
| **T04** | relight | `fg_path`, `bg_path`, `light_hint:{dir, color, intensity}` | `relit_fg_path` | IC-Light / MKL |
| **T05** | shadow | `fg_path`, `alpha_path`, `bg_path`, `shadow_hint` | `shadow_path` | 程序化阴影 / 扩散 |
| **T06** | harmonize | `fg_path`, `bg_path` | `harmonized_fg_path` | RainbowNet / MKL |
| **T07** | composite | `fg_path`, `alpha_path`, `bg_path`, `shadow_path?`, `method` | `output_path` | alpha over / Poisson |

接口约束：
- 输入/输出均为本地路径（Agent 用 file_id 索引）
- 每个工具可独立调用，也可串联为 DAG
- 全部暴露 `latency_ms`、`memory_mb`、`model_version` 三件套
- 失败时返回 `error_code` + `human_msg`

## 五、训练方案（B3）

由于本次环境为 **CPU only**（无 GPU），全量训练 BiRefNet 不可行。采取以下策略：

1. **Baseline**：直接用 BiRefNet 公开权重推理
2. **Fine-tune**：在 Distinctions-646 子集（200 张）上对 **BiRefNet 解码器**做 LoRA 微调（adapter 风格）
   - 冻结 backbone encoder（节省算力）
   - 仅训练 decoder + LoRA adapter（参数量 < 5% 总参数量）
   - 学习率 1e-4，batch=1，gradient accumulation = 8
   - 训练时长：约 4-6 小时（CPU 上 200 张 × 5 epoch）

## 六、评估指标（B4）

四项标准 matting 指标：
- **SAD** (Sum of Absolute Difference)：越小越好
- **MSE** (Mean Squared Error)：越小越好
- **Grad** (Gradient error)：越小越好（边缘质量）
- **Conn** (Connectivity error)：越小越好（连通性）

报告格式：
- 表格：baseline vs fine-tuned 在 main / hard case 子集
- 视觉对比：≥ 20 组三元组（原图 / baseline alpha / fine-tuned alpha）
- train.log / eval.csv / config.yaml 三件套齐全

## 七、光影一致性流水线（B5）

```
原始图 → T03(matting) → fg + alpha
                              ↓
                       T06(harmonize) ← bg
                              ↓
                       T04(relight) ← bg light hint
                              ↓
                       T05(shadow) ← bg geometry
                              ↓
                       T07(composite) → final
```

四组实验（B6）：
- **A**：仅 alpha 合成（无光影）
- **B**：+ Harmonization
- **C**：+ Relighting
- **D**：全流程（Ours）

主观评分（n≥10）：自然度 / 光影一致 / 颜色一致 / 边缘质量

## 十、实际执行方案与实验结果（2026-09-09 凌晨 · 实测）

### 10.1 抠图方案修正：BiRefNet 冻结 + AlphaRefiner 精修（two-stage matting）

原计划"微调 BiRefNet"在本机硬件上**不可行**，实测数据：

| 方案 | 显存占用 | 4GB 卡可行性 |
|---|---|---|
| BiRefNet 推理（1024×1024, fp16） | ~3.2 GB | ✅ 可用 |
| BiRefNet 全参/解码器微调 | 需 3–4× 推理显存（>10 GB） | ❌ 不可行 |
| **冻结 BiRefNet（no_grad 前向）+ 训练 3.35M AlphaRefiner** | < 1.5 GB | ✅ 采用 |

因此落地为工业界标准的 **two-stage matting**：
1. **Stage 1（冻结）**：BiRefNet 出粗 alpha（512 推理，显存 ~1.2GB）。
2. **Stage 2（可训练）**：`AlphaRefiner` —— 轻量 UNet（base=32，3.35M 参数），
   输入 **4 通道 = RGB(3) + 粗 alpha(1)**，输出精修 alpha。
   - 采用**残差学习**：`out = clamp(coarse + scale * (delta - 0.5))`，以粗 alpha 为起点只学残差，收敛快且不会退化到比 baseline 更差。
   - Loss = `1.0·L1 + 1.0·一阶梯度 + 0.5·Laplacian`（保边缘锐度）。
   - 训练配置：AdamW(lr=1e-3, wd=1e-4) + CosineAnnealing，AMP fp16，bs=4，384×384，768 训练样本。

> 该设计同时天然满足"留出 Agent 接口"：`AlphaRefiner` 是独立可插拔模块，
> Agent 可选择只跑 Stage 1（快）或跑全链路（精），见 `ai-service/src/matting/matting_backend.py`。

### 10.2 数据隔离（B2 验收：train/val/test 物理隔离无泄漏）

- 数据集从 320 张扩充到 **960 张**（8 类 × 120），384×384。
- 划分比例：**train 768 / val 96 / test 96**（0.8 / 0.1 / 0.1）。
- **关键处理**：目录内存在历史残留文件（早期 320 张版本的 val/test 未被覆盖），
  若按目录 glob 读取会造成 train/val/test 泄漏。
  因此**以 `data/matting/manifest.csv` 为唯一权威**，所有训练/推理/评估脚本均按 manifest 的
  `split` 字段读取（见 `load_split()`），并导出 `test_names.txt` / `val_names.txt` / `train_names.txt`。
- 七类难例每类在 test 集各 12 张，合计 96 张，满足达标数量（局部按类统计见实验报告）。

## 12. 演播室场景训练（B9）

### 12.1 动机
通用 matting 数据（几何合成）训练出的 Refiner 直接用于演播室**反退化**：
演播室 test 上 SAD 从 BiRefNet 本身的 13,982 飙到 37,574 (+168.7%) —— 经典 negative transfer.
本次重做专门面向「演播室场景」的合成数据 + 域内训练, 量化"演播室场景训练"价值.

### 12.2 演播室数据生成器 `studio_dataset.py`
显式建模演播室物理:
- **三点布光**: Key (5600K) / Fill (6500K) / Rim (冷白, 0.8), 用 distance transform + 法线 + Lambertian
- **四类背景**: greenscreen / bluescreen / led_wall / studio_set (LED 大屏 + 聚光灯 + 景深)
- **八类主体**: anchor_hair(520发丝) / glasses / gesture / motion / prop_transparent / veil / greenscreen_spill / lowlight_rim
- **绿幕溢出**: `F' = F + spill * G * 4a(1-a)` (过渡带最强)
- **真实退化**: 运动模糊 + 高斯噪声 + 色温偏移 + 暗角

960 张, train 720 / val 120 / test 120, 512×512 (2× 超采样 → 亚像素 alpha).

### 12.3 跨域对比结果（演播室 test, n=120）

| Model | SAD | MSE | Conn | 备注 |
|---|---|---|---|---|
| S0 BiRefNet512 | 13 982 | 0.0261 | 0.126 | baseline |
| S1 GeneralRefiner (跨域) | **37 574** | 0.0656 | 0.180 | **+168.7% 反退化** |
| S2 StudioRefiner (域内) | **4 091** | 0.0022 | 0.036 | **-70.7% 优于 baseline** |

S2 vs S1 改善 **89.1%** —— 这就是"演播室场景训练"的价值.

### 12.4 训练结果
`checkpoints/refiner_studio/best.pt` (3.35M 参数, 40 MB)
- best epoch 79, val=0.02966, val_l1=0.96%
- vs 通用域 val_l1=3.21% → 误差降到 30%
