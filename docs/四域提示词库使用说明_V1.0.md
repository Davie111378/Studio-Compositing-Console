# 四域提示词库使用说明（绿幕背景 / 抠图 / 特效 / 滤镜）

> 版本 V1.0 | 2026-09-10
> 语料: `data/prompt_corpus/prompt_corpus.jsonl`（9,569 条 / **242,896 字**，达标 10 万字的 2.43 倍）
> 生成器: `agent_training/build_prompt_corpus.py`（程序化组合，seed=20260910 可复现）

## 1. 设计思路

手写 10 万字提示词不现实也不可维护。本库采用**程序化组合生成**：
`领域词汇表 × 句式模板 × 参数变体 × 修饰语`，在保证语言多样性的同时，
每条提示词都携带**机器可校验的期望标注（expect）**，从而直接服务于三件事：

1. **SFT 训练**：expect → DAG 构造 → `messages` 格式训练样本
2. **held-out 评测**：val 子集上评 Tool/Order/Param 三维准确率
3. **回归测试**：改 Planner/prompt/工具后全量重放，防退化

## 3. 数据格式

```json
{"id": "A_000001", "domain": "A_green_bg",
 "text": "把 fg_01_anchor_male.png 的背景换成星空夜景, 光照要一致",
 "expect": {"tools": "FULL", "bg": "星空夜景"}}
```

expect 取值：
- `tools`: `"FULL"` | `"FULL+T07"` | `"GS"` | `"GS+T07"` | `["T01_matting"]` | `["T07_enhance"]`
- `bg`: 背景语义（传入 T02.semantic）
- `fx` / `sticker` / `text`: T07 参数
- `abstain`: true 表示拒识

## 4. 训练接入

```bash
# 1) 生成语料 + 抽样转 SFT（自动备份旧数据为 .v1.bak，防膨胀）
python agent_training/build_prompt_corpus.py

# 2) 训练（数据 2688 train / 789 val）
python agent_training/train_sft.py --epochs 2

# 3) 评测
python agent_training/eval_sft.py --engine local     # 14 条人工泛化集
python agent_training/eval_corpus.py --n_per 12      # 语料 held-out 分层评测
```

合并策略：新 train = 旧 288 条（B3 真实对 + 领域 QA 等）+ 语料抽样 2,400 条。

## 5. 复现与扩展

- 全部生成逻辑确定性（seed 固定），`corpus_stats.json` 记录字数与分布
- 新增背景语义：往 `BG_SEMANTIC` 加词即可自动进入全句式组合
- 新增特效：往 `C_FX` 加 `(key, [句式...])`
- 新增滤镜说法：往 `D_WARM` / `D_COOL` 加口语表述
- 字数不达标时生成器自动对 A/C/D 域扩量（`--target_chars` 可调）
