# 实验报告 · 演播室场景训练 (B 组 域内训练)

## 0. 任务背景与动机

**原始数据** `data/matting` 是「通用几何合成」(hair/glass/veil/transparent/semi/fine_edge/complex_bg/normal 八类), 主体是抽象几何 + 随机纹理。  
**真实部署场景** 是演播室：三点布光 + 绿幕/蓝幕/LED 大屏 + 主持人/嘉宾 + 发丝/眼镜/薄纱/玻璃杯 + 绿幕溢出 + 轮廓光 rim。

通用域训练好的 Refiner (best.pt, val_l1=3.21%) 直接搬到演播室数据上**反退化** —— 通用 Refiner 在演播室 test 上的 SAD 从 BiRefNet 本身的 13,982 涨到 **37,574** (negative transfer)。  
本文就是用**演播室场景数据**重新训练, 量化"域内训练"带来的增益。

## 1. 演播室场景数据集 (`data/studio`)

**生成器**: `training/scripts/studio_dataset.py` —— 程序化合成, 显式建模演播室物理。

### 1.1 三点布光
- Key   (5600K, 强度 1.0, 前侧 45°)
- Fill  (6500K, 强度 0.35, 反向)
- Rim   (冷白, 强度 0.8, 逆光)

实现: alpha → distance transform → 伪高度 → 法线 → Lambertian + Rim. 任意形状都成立体光照.

### 1.2 四类演播室背景 (`bg_type`)
| 背景 | 特征 |
|---|---|
| `greenscreen` | 绿幕 (0, 177, 64) + 布光不均 + 褶皱 + 暗角 |
| `bluescreen` | 蓝幕 (0, 71, 187) |
| `led_wall`   | LED 大屏虚拟演播室：深色底 + 发光块 + 光晕 + 点阵 |
| `studio_set` | 实景演播室：地板透视 + 聚光灯 + 景深虚化 + 道具剪影 |

### 1.3 八类演播室难点主体 (`case`)
| Case | 设计意图 |
|---|---|
| `anchor_hair` | 主持人, 头发丝最密 (520 条发丝) |
| `anchor_glasses` | 戴眼镜主持人, 镜片高光 + 镜腿半透明 |
| `anchor_gesture` | 手势/手指, 细长结构 + 自遮挡 |
| `guest_motion` | 快速运动, 方向性运动模糊 |
| `prop_transparent` | 透明道具 (玻璃水杯) |
| `prop_veil` | 薄纱/丝巾, 大面积半透明 + 褶皱 |
| `greenscreen_spill` | 强绿幕溢出 (边缘污染, 4a(1-a) 过渡带最强) |
| `lowlight_rim` | 逆光轮廓光, 低照度 + 强 rim |

### 1.4 真实传感器退化
运动模糊 + 高斯噪声 + 色温偏移 + 暗角.

### 1.5 数据规模与 GT
| split | n | 占比 | 物理 (W×H) |
|---|---|---|---|
| train | 720 | 75% | 512×512 (2× 超采样 → 512, 亚像素精度 alpha) |
| val   | 120 | 12.5% | 512×512 |
| test  | 120 | 12.5% | 512×512 |
| **总计** | **960** | | |

`data/studio/manifest.csv` (image, alpha, case, split, bg, lighting, spill) 作为 split 唯一权威, 杜绝目录残留导致的泄漏.

### 1.6 真实数据接入接口
`training/scripts/ingest_real.py` —— 把真实拍摄 / 第三方数据集 (Composition-1k, P3M-10k, AM-2k) 转换为统一格式, 直接 append 到 `data/studio` 的 manifest. 接口稳定, 不依赖具体来源.

## 2. 实验设置

| | 模型 | 训练数据 | 评估数据 |
|---|---|---|---|
| **S0** | BiRefNet@512 (粗 alpha) | (无) | studio/test |
| **S1** | BiRefNet + 通用 Refiner (跨域) | data/matting (768 train) | studio/test (跨域!) |
| **S2** | BiRefNet + 演播室 Refiner (域内) | data/studio (720 train) | studio/test (域内) |

训练配置: 80 epoch × 20s = 27 分钟; bs=4; lr=1e-3 (余弦退火); size=384; base=32 (3.35M 参数); Adam; L1 + 一阶梯度 + Laplacian loss.

## 3. 跨域对比结果 (演播室 test, n=120)

| Model | SAD | MSE | Grad | Conn | 相对 S0 SAD | 相对 S1 SAD |
|---|---|---|---|---|---|---|
| S0 BiRefNet512 | 13 982 | 0.02609 | 0.01 | 0.126 | — | — |
| S1 GeneralRefiner (跨域) | **37 574** | 0.06560 | 0.01 | 0.180 | **+168.7% ⚠️** | — |
| S2 StudioRefiner (域内) | **4 091** | 0.00221 | 0.00 | 0.036 | **-70.7%** | **-89.1%** |

### 3.1 关键观察

**1. 跨域 = 反退化 (S1 ≫ S0)**  
通用域训练好的 Refiner 直接搬到演播室, SAD 从 13,982 飙到 37,574 (+168.7%). 这是经典的 **negative transfer** —— 通用几何合成数据上没有"绿幕溢出 + 3 点布光 + 真实镜头退化"这些物理分布, Refiner 学到的残差方向在演播室数据上完全失效, 甚至把 BiRefNet 的合理输出"矫枉过正".

**2. 域内训练 = 显著增益 (S2 ≪ S0)**  
演播室域训练的 Refiner 比 BiRefNet baseline 还低 70.7%, Conn (边界连通性) 从 0.126 → 0.036 (-71.3%), 表明 Refiner 在演播室真实分布上学会了:
- 头发丝的精细过渡 (发丝 520 条, 真实发丝半透明)
- 绿幕溢出区与前景的边缘区分 (4a(1-a) 过渡带)
- 眼镜/薄纱的半透明区域
- Rim light 引起的边缘高光的 alpha 修正

**3. S2 vs S1 跨域提升 89.1%**  
这量化了"演播室场景训练" (用户本次需求) 带来的本质收益 —— 不只是"略好", 而是数量级的差异.

## 4. 训练配置 (`refiner_studio`)

`training/checkpoints/refiner_studio/best.pt` (40 MB, 3.35M 参数)
- best epoch: 79, best val=0.02966, val_l1=0.96%
- vs 通用域 refiner/best.pt: best val=0.05281, val_l1=3.21%
- val loss 直接降到通用域的 56%, val_l1 误差降到通用域的 30%

泛化证据: 演播室 test SAD 4,091 (域内) vs 通用 test SAD 5,615 (域内). 演播室域 test 的 GT 比通用域 test 复杂得多 (发丝 + 配件 + 真实退化), 但 S2 误差更低 —— 演播室训练数据**结构匹配** > 通用训练数据**样本数量**.

## 7. 后续建议

1. **真实数据微调**: 用 `ingest_real.py` 接入 P3M-10k / AM-2k 等真实演播室人像数据集, 在 `refiner_studio` 基础上继续微调 (LoRA 风格, 只调最后两层).
2. **高分辨率训练**: 当前训练 384px, 可升级到 512/640 (4GB 显存能撑住 bs=2).
3. **曝光 / 色温鲁棒**: 训练数据色温偏移范围可加大 (-0.1 ~ +0.1), 适应多机位色温差.
4. **多 rim 方向**: 当前 rim 固定 (-, -, -), 可随机化方向模拟真实侧光 / 顶光轮廓.
