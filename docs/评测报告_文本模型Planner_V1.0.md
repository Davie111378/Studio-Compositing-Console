## 3. 评测发现并修复的 2 个真 Bug

1. **兜底模板漏“导出”关键词**（`planner.py`）：G6-01(lite) 两次 JSON 解析失败落兜底后，生成的链没有 T08_export，用户要求“最后导出”被静默丢弃。
   → 已修复：链尾按需追加 T08（识别 导出/保存/输出成/存成），并修正 $nN.final_path 引用。
2. **评测脚本违禁词误判**（`planner_eval.py`）：违禁词原扫全 params 文本，T07 参数路径含 "video" 字样被误报。
   → 已修复：违禁词只匹配工具名。

## 4. 遗留问题与建议（P1）

1. **延迟**：首过 8.9s、带重试 26s、strict fewshot 峰值 70s。建议：压缩 system prompt（现在含全部 8 工具 schema）+ max_tokens 1400→900 + 输出流式；目标首过 ≤4s。
2. **首次直通率 73%**：5 次重试均成功收敛（带错误反馈自愈有效），可把高频错误模式（枚举大小写、$nN 引用格式）补进 fewshot。
3. **fewshot 选择**：`best` 变体速度/质量最均衡，建议 `plan()` 默认改 `fewshot_variant="best"`。
4. G5 乱码输入 "asdfghjkl" 模型仍生成了合法 DAG（schema 安全但意图是猜的）——建议 planner 对低置信输入显式走澄清话术而非猜测。
